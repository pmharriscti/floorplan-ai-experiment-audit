# Visual QA

These are historical Phase 3A.2 three-way geometry sheets copied from the source run. They were generated by `scripts/run_phase3a2_opening_axis_repair.py`; they are not screenshots reconstructed for this audit and are not model predictions.

Each sheet contains nine panels:

1. original floorplan crop;
2. highlighted source SVG instance;
3. door leaf and swing evidence;
4. host-wall evidence;
5. door-jamb evidence;
6. `candidate_v3` target;
7. `candidate_v3.1` target;
8. `candidate_v3.2` target;
9. version comparison, with red for v3, yellow for v3.1, and green for v3.2.

| File | Why it is useful |
| --- | --- |
| [10543 / door_0003](geometry_updates/high_quality_architectural__10543__door_0003__door_opening.png) | Shows a vertical source threshold and host-wall/jamb evidence against the v3.1 horizontal synthesis. |
| [11709 / door_0012](geometry_updates/high_quality_architectural__11709__door_0012__door_opening.png) | Shows the source-evidenced jamb-to-jamb target and the version-specific geometry together. |
| [8690 / door_0005](geometry_updates/high_quality_architectural__8690__door_0005__door_opening.png) | Shows a difficult nearby-wall context where explicit source geometry matters. |

The full source paths are recorded in [provenance.json](../provenance.json), and per-image dimensions and hashes are in [geometry_updates/metadata.json](geometry_updates/metadata.json). Pixel dimensions are `1320 x 1078`, RGB PNG.
